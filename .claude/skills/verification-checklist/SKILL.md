# 動作確認・禁止事項・最終チェック

## 禁止事項

- デザインにないものを勝手に追加する（装飾・カード化・アニメーション・構成変更）
- CSS Modules や通常 CSS に逃げる
- 同じようなコードを大量に重複させる
- 画像パスを実在しない外部 URL にする
- `alt="画像"` のような意味のない alt
- コメントアウトに作業メモを残す
- PC だけ整えて SP を崩れたままにする / 横スクロールが出る実装
- `style={{ }}` を多用する / 不要なライブラリを追加する
- 使っていないコードを残す / 既存コードを確認せず上書きする
- `text-[...]` や `px-[...]` の計算式を、ブレイクポイントごとに重複して書く

## 動作確認

実装後、可能な範囲で以下を実行し、結果を報告する。

```bash
npm run lint
npm run build
```

エラーが出た場合は修正し、再度実行する。

## 出力時の報告フォーマット

1. 作成・変更したファイル一覧
2. 画像パス一覧（必要な素材）
3. 実装上の注意点
4. `npm run lint` / `npm run build` の結果

## 最終チェック

- PC 幅でデザインと見た目が近いか
- tablet 幅で余白・カラムが崩れていないか
- SP 幅で横スクロールが出ていないか
- 画像が潰れていないか / テキストが小さくなりすぎていないか
- デザインにない装飾を追加していないか / 既存コードを不要に壊していないか
- CSS 変数の値だけ変更すれば各ブレイクポイントのサイズ調整ができる状態か
- position: absolute を使った箇所は、CLAUDE.md の絶対配置ルールに沿ってスケール済みの値になっているか
